Configuration

Every option accepted by the Namecheap client.

const nc = new Namecheap({
  apiUser: "your-api-user", // string, required: your API user name
  apiKey: "your-api-key", // string, required: your API key
  clientIp: "203.0.113.10", // string, required: the whitelisted IP the requests come from
  userName: "account-name", // string, optional: the account to act on, defaults to apiUser
  sandbox: true, // boolean, optional: defaults to false (PRODUCTION)
  fetch: globalThis.fetch, // optional: your own fetch implementation
  timeoutMs: 15_000, // number, optional: abort a request after this many milliseconds
});

Sandbox vs production

Warning. sandbox defaults to false, which means PRODUCTION. Forgetting it sends real, billed commands (registrations, renewals, transfers) and changes real DNS. Set sandbox: true explicitly while developing.

sandbox must be a real boolean: a string such as "true" throws a TypeError at construction instead of silently selecting production. Convert environment variables yourself:

sandbox: process.env.NAMECHEAP_SANDBOX === "true"

IP whitelist

Namecheap rejects requests from IP addresses that are not on your API whitelist, in the sandbox and in production. Enable API access and add your server's public IP in the Namecheap dashboard (Profile → Tools → Namecheap API Access), and pass the same address as clientIp.

Credentials travel in the POST body (application/x-www-form-urlencoded), never in the URL, so they do not end up in access logs or proxies that record URLs.
