Commands that spend money or change ownership or DNS (for example domains.create, domains.renew, transfer.create, ssl.create and dns.setHosts) deserve extra care; see Errors & safety.

Command tables

The package also exports the command tables behind each group (domainsCommands, dnsCommands, and so on) for custom integrations. They are advanced API and are not covered by semver stability, so prefer nc.<group>.<method>.
